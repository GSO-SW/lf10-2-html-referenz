# HTML-Referenz

Georg-Simon-Ohm-Berufskolleg · Fachinformatik Anwendungsentwicklung

Dein Nachschlagewerk für HTML: kommentierte, funktionierende Beispiele statt
langer Tag-Listen.

## 👉 Du hast eine Frage? → [NACHSCHLAGEN.md](NACHSCHLAGEN.md)

Dort steht zu jeder typischen Frage („Wie formatiere ich einen Button?“) ein
Link, der direkt auf die passende **Datei und Zeile** springt.

## Was ist hier drin?

| | |
|---|---|
| [`NACHSCHLAGEN.md`](NACHSCHLAGEN.md) | Fragen → Code-Stelle (das „Cheat Sheet“) |
| [`referenz/`](referenz/) | 10 Beispielseiten + Stylesheet. Die Erklärungen stehen als Kommentare im Code. |
| [`referenz/index.html`](referenz/index.html) | Übersicht aller Beispielseiten |

## So benutzt du die Beispiele

**Nur lesen:** Klicke in [NACHSCHLAGEN.md](NACHSCHLAGEN.md) auf einen Link. GitHub zeigt
den Code und markiert die passenden Zeilen gelb.

**Im Browser ansehen und ausprobieren:**

1. Oben auf **Code → Download ZIP** klicken und entpacken
   (oder `git clone` – wenn du weißt, was das ist 😉).
2. Den Ordner in VS Code öffnen.
3. `referenz/index.html` → Rechtsklick → **Open with Live Server**
   (Erweiterung „Live Server“ einmalig installieren).

Jetzt kannst du Code und Ergebnis nebeneinander sehen und in den Beispielen
herumprobieren – kaputt machen ist erlaubt, du hast ja eine Kopie.
