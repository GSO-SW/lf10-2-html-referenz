CSS-Grundlagen: Regeln schreiben und einbinden

HTML sagt, was etwas ist. CSS (Cascading Style Sheets) regelt, wie es aussieht. Öffne neben dieser Seite auch css/11-grundlagen.css im Editor.

Aufbau einer CSS-Regel

Jede Regel besteht aus einem Selektor (wen?) und einem Deklarationsblock (was?). Eine Deklaration ist ein Paar aus Eigenschaft und Wert, abgeschlossen mit einem Semikolon.

h2 {                       ← Selektor
  color: #0b5cad;          ← Deklaration: Eigenschaft: Wert;
  font-size: 1.5rem;
}                          ← Ende des Deklarationsblocks

Dieser Absatz wird durch die Regel .regel-beispiel gestaltet.

Einbindungsarten im Vergleich
Art Schreibweise Gilt für Einsatz
Extern <link rel="stylesheet" href="style.css"> alle Seiten, die die Datei verlinken Standard im Projekt
Im Kopf <style> … </style> nur diese Seite Experimente, Einzelseiten
Inline style="…" nur dieses Element vermeiden
Import @import url("x.css"); wie die importierende Datei nur ganz oben in einer CSS-Datei, lädt langsamer

Wenn eine Regel nicht wirkt

Fehlerhafte Deklarationen ignoriert der Browser stillschweigend. Typische Ursachen findest du im Stylesheet unter css-fehler. Prüfen kannst du dein CSS mit dem CSS-Validator des W3C und in den Entwicklertools (F12), siehe 13-kaskade.html.
