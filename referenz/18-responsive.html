Responsive Design: eine Seite für alle Geräte

Statisch, flüssig, responsiv

  • Statisch: feste Breite in px. Auf dem Handy waagerecht scrollen.
  • Flüssig: Breiten in %. Passt immer, wird auf dem Handy aber zu schmal.
  • Responsiv: flüssig + Media Queries. Das Layout ändert sich an Umbruchpunkten.

Demo: Spalten je nach Breite

Handy: untereinander

ab 40rem: zwei Spalten

ab 64rem: drei Spalten

So testest du

  1. F12 → Symbol „Gerätesymbolleiste“ (Strg + Umschalt + M) → Breite 375 und 320.
  2. Fenster langsam schmaler ziehen: Wo bricht etwas? Dort braucht es einen Umbruchpunkt.
  3. Zoom 400 % (Strg + +): kein waagerechtes Scrollen (WCAG 1.4.10).
  4. Auf einem echten Handy öffnen (z. B. über den Live Server im selben WLAN).
